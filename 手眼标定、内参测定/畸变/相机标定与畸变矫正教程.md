## 1. 相机成像模型

### 1.1 针孔相机模型

理想情况下，相机可以用**针孔模型**描述。这个模型的核心思想是：光线从物体发出，经过一个微小的针孔后，在针孔后方的屏幕上形成倒立的像。

#### 1.1.1 模型示意图

```
              像平面 (image plane)
          ┌──────────────────────┐
          │                      │
          │        • (x, y)      │  ← 成像点（倒立的像）
          │       /              │
          │      /               │
          │     /                │
          │    /                 │
          │   /                  │
          │  /                   │
          │ /                    │
          └•─────────────────────┘
           │  f                  │
           │  ← 焦距 →           │
           • 光心 (optical center)
           │
           │
           │ Z
           ↓
    • (X, Y, Z)  ← 世界中的3D点（真实物体）
```

**关键点**：
- 光心是镜头的中心点
- 像平面与光心的距离就是**焦距 f**
- 物体上的点、光心、像点三点共线（直线传播）

#### 1.1.2 相似三角形推导

小孔成像公式的核心原理是**相似三角形**。让我们只看 X-Z 平面上的投影：

```
                    像平面
              ┌──────────────┐
              │              │
              │      x       │  ← 像点到光轴的水平距离
              │    ←──→      │
              │    •─────────•
              │    │\        │
              │    │ \       │
              │    │  \      │
              │  f │   \     │
              │    │    \    │
              │    │     \   │
              │    │      \  │
              └────•────────•──┘
                   │\       /
                   │ \     /
                   │  \   /
                   │   \ /
                   •────•  ← 光心
                   │\
                   │ \
                   │  \
                   │   \
                   │    \
                   │     \  Z  ← 物体到光心的距离
                   │      \
                   │       \
                   •────────•  ← 物体点
                    ←──→
                     X  ← 物体到光轴的水平距离
```

**两个相似三角形**：
1. **大三角形**：光心 → 物体点 → 光轴上的垂足（底边 = X，高 = Z）
2. **小三角形**：光心 → 像点 → 光轴上的垂足（底边 = x，高 = f）

因为这两个三角形相似（对应角相等），所以它们的对应边成比例：

$$\frac{\text{大三角形底边}}{\text{大三角形高}} = \frac{\text{小三角形底边}}{\text{小三角形高}}$$

代入具体的长度：

$$\frac{X}{Z} = \frac{x}{f}$$

两边同时乘以 f，得到：

$$x = f \cdot \frac{X}{Z}$$

同样的道理，在 Y-Z 平面上：

$$y = f \cdot \frac{Y}{Z}$$

#### 1.1.3 公式含义解读

这两个公式告诉我们：

| 公式 | 含义 |
|------|------|
| $x = f \cdot \frac{X}{Z}$ | 像平面上的水平坐标 = 焦距 × (物体水平坐标 / 物体到相机的距离) |
| $y = f \cdot \frac{Y}{Z}$ | 像平面上的垂直坐标 = 焦距 × (物体垂直坐标 / 物体到相机的距离) |

**直观理解**：
1. **Z 越小（物体越近）**：像越大（因为分母变小）
2. **Z 越大（物体越远）**：像越小（因为分母变大）
3. **f 越大（焦距越长）**：像越大（长焦镜头放大远处物体）
4. **f 越小（焦距越短）**：像越小（广角镜头容纳更多场景）

**数值示例**：
```
假设有一个物体：
- 距离相机 Z = 1 米
- 水平位置 X = 0.1 米（距离光轴 10cm）
- 相机焦距 f = 0.015 米（15mm）

计算像平面上的位置：
x = f × X/Z = 0.015 × (0.1 / 1) = 0.0015 米 = 1.5 毫米

→ 物体在像平面上的投影距离光轴 1.5mm
```

#### 1.1.4 重要注意事项

> ⚠️ **符号问题**：在上面的推导中，为了简化，我们假设物体在相机前方（Z > 0），且像平面在光心后方（f > 0）。在实际的数学模型中：
> - 当物体在光轴右侧（X > 0）时，像点在光轴左侧（x < 0）
> - 这意味着成像是**倒立的**
> - 但在最终的像素坐标系中，我们会通过坐标变换把图像"正过来"，所以通常不关心这个符号问题

> ⚠️ **简化假设**：上面的推导假设物体在相机坐标系下（即光心是原点）。如果物体在世界坐标系下，需要先通过外参转换到相机坐标系。

其中：
- `(X, Y, Z)` — 相机坐标系下的 3D 点（注意：不是世界坐标系）
- `(x, y)` — 像平面上的物理坐标（单位：米）
- `f` — 焦距（单位：米）

### 1.2 四个坐标系详解

在理解相机成像模型之前，必须先明确**四个核心坐标系**及其相互关系。这是理解后续公式的关键。

#### 1.2.1 世界坐标系 (World Coordinate System)

**符号**：$(X_w, Y_w, Z_w)$

**定义**：
- 原点：通常选在标定板的某个固定点（如左上角内角点）
- X轴：沿标定板水平方向向右
- Y轴：沿标定板垂直方向向下
- Z轴：垂直于标定板平面，指向相机方向

**用途**：描述标定板上每个角点的真实物理位置，与相机无关。

**示例**：
```
标定板上某个内角点的世界坐标：
(X_w, Y_w, Z_w) = (0.030, 0.045, 0)
→ 距离原点水平 30mm，垂直 45mm，在标定板平面上（Z=0）
```

#### 1.2.2 相机坐标系 (Camera Coordinate System)

**符号**：$(X_c, Y_c, Z_c)$

**定义**：
- 原点：**光心（镜头中心点）**
- X轴：与图像平面的水平方向平行，向右为正
- Y轴：与图像平面的垂直方向平行，向下为正
- Z轴：沿**主光轴**方向，指向被拍摄物体（向前为正）

**用途**：描述空间点相对于相机的位置。

> ⚠️ **重要约定**：OpenCV 使用的是**右手坐标系**，即 X × Y = Z。想象你拿着相机拍照：
> - 右手拇指指向 X（向右）
> - 食指指向 Y（向下）
> - 中指自然指向 Z（向前，指向你拍摄的物体）

#### 1.2.3 图像物理坐标系 (Image Physical Coordinate System)

**符号**：$(x, y)$

**定义**：
- 原点：**主点（principal point）**，即主光轴与图像平面的交点
- x轴：与相机坐标系X轴平行，向右为正
- y轴：与相机坐标系Y轴平行，向下为正
- 单位：**米（m）**，物理尺寸

**用途**：描述成像点在传感器上的物理位置。

**特点**：
- 这个坐标系的原点不一定在图像中心（可能有微小偏移）
- 坐标值可以是正数也可以是负数（原点在中间）

#### 1.2.4 像素坐标系 (Pixel Coordinate System)

**符号**：$(u, v)$

**定义**：
- 原点：**图像左上角**
- u轴：水平向右为正
- v轴：垂直向下为正
- 单位：**像素**

**用途**：这是我们最终在代码中使用的坐标系，用于索引图像数组。

**四个坐标系的转换关系**：

```
世界坐标系 (Xw,Yw,Zw)
      ↓ 外参 (R, t)
相机坐标系 (Xc,Yc,Zc)
      ↓ 透视投影 (除以 Zc)
图像物理坐标系 (x, y)  [单位: 米]
      ↓ 除以像素尺寸 + 原点偏移
像素坐标系 (u, v)  [单位: 像素]
```

### 1.3 像素坐标系

传感器上的物理坐标（单位：米）需要映射到像素坐标（单位：像素），这个转换分为**两步**。

#### 1.3.1 第一步：物理坐标 → 像素坐标（不考虑原点偏移）

物理坐标 $(x, y)$ 的单位是米，我们需要转换成像素单位。这需要知道**像素的物理尺寸**：

- `dx`：单个像素在水平方向的物理尺寸（单位：米/像素）
- `dy`：单个像素在垂直方向的物理尺寸（单位：米/像素）

转换公式：

$$u' = \frac{x}{dx}, \quad v' = \frac{y}{dy}$$

**含义**：用物理距离除以单个像素的尺寸，得到像素数量。

#### 1.3.2 第二步：原点偏移

物理坐标系的原点在**主点（图像中心附近）**，而像素坐标系的原点在**图像左上角**。所以需要加上偏移量：

$$u = u' + c_x = \frac{x}{dx} + c_x$$
$$v = v' + c_y = \frac{y}{dy} + c_y$$

其中：
- `(c_x, c_y)` — 主点的像素坐标，即物理坐标系原点在像素坐标系中的位置
- 通常 `c_x ≈ 图像宽度/2`，`c_y ≈ 图像高度/2`

#### 1.3.3 整合公式

将小孔成像公式 $x = f \cdot \frac{X}{Z}$ 代入：

$$u = \frac{f}{dx} \cdot \frac{X}{Z} + c_x = f_x \cdot \frac{X}{Z} + c_x$$
$$v = \frac{f}{dy} \cdot \frac{Y}{Z} + c_y = f_y \cdot \frac{Y}{Z} + c_y$$

其中：
- `f_x = f / dx` — x 方向的焦距（像素单位）
- `f_y = f / dy` — y 方向的焦距（像素单位）

#### 1.3.4 完整数值示例

假设：
```
相机参数：
- 焦距 f = 0.015 米（15mm）
- 像素尺寸 dx = 2.2e-6 米（2.2微米），dy = 2.2e-6 米
- 主点 c_x = 628.5 像素，c_y = 452.3 像素

物体位置（相机坐标系）：
- X = 0.1 米（距离光轴 10cm）
- Y = 0.05 米（距离光轴 5cm）
- Z = 1 米（距离相机 1 米）
```

**计算步骤**：

1. **计算像平面物理坐标**：
```
x = f × X/Z = 0.015 × (0.1/1) = 0.0015 米 = 1.5 mm
y = f × Y/Z = 0.015 × (0.05/1) = 0.00075 米 = 0.75 mm
```

2. **计算像素坐标（不带偏移）**：
```
u' = x/dx = 0.0015 / 2.2e-6 ≈ 681.8 像素
v' = y/dy = 0.00075 / 2.2e-6 ≈ 340.9 像素
```

3. **加上主点偏移**：
```
u = u' + c_x = 681.8 + 628.5 = 1310.3 像素
v = v' + c_y = 340.9 + 452.3 = 793.2 像素
```

4. **最终结果**：
```
物体在图像中的像素坐标：(1310, 793)
```

#### 1.3.5 直观理解

```
物理坐标系（原点在主点）：
              ┌──────────────────────┐
              │                      │
              │    • 主点 (0, 0)     │
              │   / \                │
              │  /   \               │
              │ /     \              │
              │/       \             │
              •────────•             │
              │   dx   │             │
              └──────────────────────┘
                    ↓ 除以 dx/dy + 偏移
像素坐标系（原点在左上角）：
              ┌──────────────────────┐
              │ • (0, 0)             │  ← 左上角原点
              │   ↓                  │
              │   →                  │
              │                      │
              │          • (cx, cy)  │  ← 主点位置
              │                      │
              └──────────────────────┘
```

#### 1.3.6 参数含义总结

| 参数 | 符号 | 单位 | 含义 |
|------|------|------|------|
| 焦距（物理） | f | 米 | 光心到像平面的距离 |
| 像素尺寸（水平） | dx | 米/像素 | 单个像素的宽度 |
| 像素尺寸（垂直） | dy | 米/像素 | 单个像素的高度 |
| 焦距（像素，水平） | f_x = f/dx | 像素 | 水平方向的有效焦距 |
| 焦距（像素，垂直） | f_y = f/dy | 像素 | 垂直方向的有效焦距 |
| 主点（水平） | c_x | 像素 | 主点的水平像素坐标 |
| 主点（垂直） | c_y | 像素 | 主点的垂直像素坐标 |

### 1.4 相机内参矩阵

#### 1.4.1 齐次坐标简介

在理解矩阵形式之前，需要先了解**齐次坐标**。齐次坐标是一种将 n 维坐标表示为 n+1 维的方法：

| 坐标类型 | 表示方式 | 用途 |
|---------|---------|------|
| 2D 欧几里得坐标 | $(u, v)$ | 常规像素坐标 |
| 2D 齐次坐标 | $(su, sv, s)$ | 表示 2D 点（s ≠ 0） |
| 3D 欧几里得坐标 | $(X, Y, Z)$ | 常规空间坐标 |
| 3D 齐次坐标 | $(X, Y, Z, 1)$ | 表示 3D 点 |

**齐次坐标的优势**：可以用矩阵乘法统一表示平移和旋转，而不需要分开处理。

#### 1.4.2 矩阵形式的推导

回顾之前的标量公式：

$$u = f_x \cdot \frac{X}{Z} + c_x$$
$$v = f_y \cdot \frac{Y}{Z} + c_y$$

我们可以把它们改写为：

$$uZ = f_x \cdot X + c_x \cdot Z$$
$$vZ = f_y \cdot Y + c_y \cdot Z$$

这可以写成矩阵形式：

$$
Z \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} =
\begin{bmatrix}
f_x & 0 & c_x \\
0 & f_y & c_y \\
0 & 0 & 1
\end{bmatrix}
\begin{bmatrix} X \\ Y \\ Z \end{bmatrix}
$$

#### 1.4.3 缩放因子 s 的含义

在一般形式中，我们用 `s` 代替 `Z`：

$$
s \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} =
\underbrace{\begin{bmatrix}
f_x & 0 & c_x \\
0 & f_y & c_y \\
0 & 0 & 1
\end{bmatrix}}_{\text{相机内参矩阵 } K}
\begin{bmatrix} X \\ Y \\ Z \end{bmatrix}
$$

**为什么需要 s？**

- 透视投影会**丢失深度信息**（3D → 2D）
- 不同深度的点可能投影到同一个像素位置
- `s` 实际上就是相机坐标系中的 Z 值（物体到相机的距离）
- 在实际计算中，我们通常不关心 s 的具体值，只需要齐次坐标转换后的前两维

**从齐次坐标到像素坐标**：

$$
s \cdot u = f_x \cdot X + c_x \cdot Z \quad \Rightarrow \quad u = \frac{f_x \cdot X + c_x \cdot Z}{s} = \frac{f_x \cdot X + c_x \cdot Z}{Z} = f_x \cdot \frac{X}{Z} + c_x
$$

$$
s \cdot v = f_y \cdot Y + c_y \cdot Z \quad \Rightarrow \quad v = \frac{f_y \cdot Y + c_y \cdot Z}{s} = \frac{f_y \cdot Y + c_y \cdot Z}{Z} = f_y \cdot \frac{Y}{Z} + c_y
$$

$$
s \cdot 1 = Z \quad \Rightarrow \quad s = Z
$$

这正是我们之前推导的公式！

#### 1.4.4 内参矩阵的结构

这就是 **相机内参矩阵 (Camera Matrix / Intrinsic Matrix)** `mtx`，OpenCV 输出的是一个 3×3 矩阵：

```
[[fx,  0, cx],
 [ 0, fy, cy],
 [ 0,  0,  1]]
```

**矩阵各元素含义**：

| 位置 | 元素 | 含义 |
|------|------|------|
| (0,0) | f_x | 水平方向焦距（像素单位） |
| (0,2) | c_x | 主点水平坐标（像素单位） |
| (1,1) | f_y | 垂直方向焦距（像素单位） |
| (1,2) | c_y | 主点垂直坐标（像素单位） |
| (0,1), (1,0), (2,0), (2,1) | 0 | 无畸变时为0 |
| (2,2) | 1 | 齐次坐标的缩放因子 |

#### 1.4.5 典型值示例

```
fx = 842.3    (像素单位的水平焦距)
fy = 843.7    (像素单位的垂直焦距)
cx = 628.5    (主点x坐标 ≈ 图像宽度的一半)
cy = 452.3    (主点y坐标 ≈ 图像高度的一半)
```

**为什么 fx 和 fy 可能不相等？**
- 理想情况下 fx = fy（正方形像素）
- 实际中可能因为制造误差或镜头畸变略有差异
- 在标定过程中，OpenCV 会自动求解这两个值

### 1.5 相机外参

内参描述相机**自身属性**（焦距、主点），外参描述相机在**世界中的位置和朝向**。

#### 1.5.1 为什么需要外参？

之前的推导都假设物体在**相机坐标系**下，但实际标定中：
- 标定板角点的坐标是在**世界坐标系**下定义的（如 (0,0,0), (0.015,0,0), ...）
- 需要把世界坐标系下的点转换到相机坐标系下
- 这个转换由外参完成

#### 1.5.2 外参的组成

外参包含两个部分：

| 组件 | 符号 | 维度 | 含义 |
|------|------|------|------|
| 旋转矩阵 | **R** | 3×3 | 描述世界坐标系相对于相机的旋转 |
| 平移向量 | **t** | 3×1 | 描述世界坐标系原点相对于相机的位置 |

#### 1.5.3 坐标转换公式

将世界坐标系下的点 $(X_w, Y_w, Z_w)$ 转换到相机坐标系下的点 $(X_c, Y_c, Z_c)$：

$$\begin{bmatrix} X_c \\ Y_c \\ Z_c \\ 1 \end{bmatrix} =
\begin{bmatrix}
\mathbf{R} & \mathbf{t} \\
0 & 1
\end{bmatrix}
\begin{bmatrix} X_w \\ Y_w \\ Z_w \\ 1 \end{bmatrix}$$

展开后：

$$X_c = R_{11}X_w + R_{12}Y_w + R_{13}Z_w + t_x$$
$$Y_c = R_{21}X_w + R_{22}Y_w + R_{23}Z_w + t_y$$
$$Z_c = R_{31}X_w + R_{32}Y_w + R_{33}Z_w + t_z$$

其中：
- **R** 是 3×3 正交矩阵（列向量相互正交且单位长度）
- **t** 是 3×1 向量（单位：米）

#### 1.5.4 旋转矩阵的性质

旋转矩阵 **R** 必须满足：
1. $\mathbf{R}^T \mathbf{R} = \mathbf{I}$（正交性）
2. $\det(\mathbf{R}) = 1$（行列式为1，保证是旋转而非反射）

#### 1.5.5 Rodrigues 向量

在 OpenCV 中，旋转矩阵不是直接存储的，而是用 **Rodrigues 向量** (rvec) 表示：

| 表示方式 | 维度 | 优点 |
|---------|------|------|
| 旋转矩阵 | 9 个数 | 数学运算方便 |
| Rodrigues 向量 | 3 个数 | 存储空间小，优化时参数少 |

**转换方法**：
```python
# 旋转向量 → 旋转矩阵
R, _ = cv2.Rodrigues(rvec)

# 旋转矩阵 → 旋转向量
rvec2, _ = cv2.Rodrigues(R)
```

**Rodrigues 向量的含义**：
- 向量的方向表示旋转轴
- 向量的长度表示旋转角度（弧度）

#### 1.5.6 完整的投影流程

把所有步骤整合起来，完整的相机投影流程是：

$$
\underbrace{\text{世界坐标 } (X_w, Y_w, Z_w)}_{\text{已知}}
\xrightarrow{\text{外参 } (R, t)}
\underbrace{\text{相机坐标 } (X_c, Y_c, Z_c)}_{\text{中间结果}}
\xrightarrow{\text{内参 } K}
\underbrace{\text{像素坐标 } (u, v)}_{\text{最终结果}}
$$

用矩阵表示：

$$
s \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = 
\mathbf{K} 
\begin{bmatrix} \mathbf{R} & \mathbf{t} \end{bmatrix} 
\begin{bmatrix} X_w \\ Y_w \\ Z_w \\ 1 \end{bmatrix}
$$

#### 1.5.7 外参的特点

> ⚠️ **重要**：每幅标定图像都有**独立的一组外参** `(rvec, tvec)`！
> - 因为标定板在不同位置和角度拍摄
> - 每张图像对应不同的外参
> - 但所有图像共用同一个内参（相机本身没变）

## 2. 畸变模型

### 2.1 为什么会有畸变？

针孔模型假设光线沿直线传播，但实际透镜是弯曲的，导致光线在边缘发生偏折。主要有两类畸变：

| 类型 | 原因 | 表现 |
|------|------|------|
| **径向畸变** Radial | 透镜曲率导致边缘放大率不一致 | 桶形畸变 (barrel) 或 枕形畸变 (pincushion) |
| **切向畸变** Tangential | 透镜与传感器不完全平行 | 图像一侧比另一侧放大更多 |

### 2.2 径向畸变公式

归一化像平面坐标 `(x, y)`（即除以 Z 后的坐标）经过径向畸变变为 `(x_distorted, y_distorted)`：

$$x_{distorted} = x(1 + k_1 r^2 + k_2 r^4 + k_3 r^6)$$
$$y_{distorted} = y(1 + k_1 r^2 + k_2 r^4 + k_3 r^6)$$

其中 $r^2 = x^2 + y^2$，`(k1, k2, k3)` 是**径向畸变系数**。

- **k1, k2, k3 > 0** → 枕形畸变（边缘拉伸）
- **k1 < 0** → 桶形畸变（边缘收缩，最常见）

### 2.3 切向畸变公式

由于装配误差，透镜中心可能不完全对准传感器中心：

$$x_{tangential} = 2p_1xy + p_2(r^2 + 2x^2)$$
$$y_{tangential} = p_1(r^2 + 2y^2) + 2p_2xy$$

其中 `(p1, p2)` 是**切向畸变系数**。

### 2.4 完整的畸变系数向量

OpenCV 使用 5 参数或 8 参数模型：

```
dist = [k1, k2, p1, p2, k3]    # 5参数（常用）
dist = [k1, k2, p1, p2, k3, k4, k5, k6]  # 8参数（广角/鱼眼镜头）
```

你的项目中使用的是 **5 参数模型**。

### 2.5 畸变示意图

```
桶形畸变 (Barrel)              枕形畸变 (Pincushion)

    ╱──────╲                      ╲        ╱
   │        │                     │  ╲    ╱  │
   │        │     ← 直线变           │    ╳    │  ← 直线凹
   │        │     向外凸              │  ╱    ╲  │     进去
    ╲        ╱                      ╱        ╲

   常见于广角镜                     常见于长焦镜
```

### 2.6 去畸变（Undistortion）

去畸变是畸变的逆过程：对输出图像的每个像素，计算它在畸变图像中的来源位置，然后插值得到像素值。

```python
# 方法1：直接 undistort（简单但较慢）
undistorted = cv2.undistort(img, mtx, dist, None, newmtx)

# 方法2：预计算映射表 + remap（推荐，适合实时处理）
map1, map2 = cv2.initUndistortRectifyMap(mtx, dist, None, newmtx, size, cv2.CV_32FC1)
undistorted = cv2.remap(img, map1, map2, cv2.INTER_LINEAR)
```

`newmtx` 是通过 `cv2.getOptimalNewCameraMatrix()` 计算的**最优新内参矩阵**，它控制着去畸变后的裁剪策略。

## 3. 张正友标定法原理

### 3.1 核心思想

1989年张正友提出了一种**基于单视图几何**的相机标定方法，获 CVPR 2000 最佳论文奖。其核心洞察是：

> **标定板的平面投影 = 单应性变换 (Homography)**

### 3.2 数学推导

#### Step 1: 世界坐标系到像平面的映射

对于标定板上的一个 3D 点 $(X_w, Y_w, Z_w)$，经过外参变换到相机坐标系：

$$\begin{bmatrix} X_c \\ Y_c \\ Z_c \end{bmatrix} = \mathbf{R} \begin{bmatrix} X_w \\ Y_w \\ Z_w \end{bmatrix} + \mathbf{t}$$

由于标定板是平的，设 $Z_w = 0$，则：

$$\begin{bmatrix} X_c \\ Y_c \\ Z_c \end{bmatrix} = \begin{bmatrix} r_{11} & r_{12} & r_{13} & t_x \\ r_{21} & r_{22} & r_{23} & t_y \\ r_{31} & r_{32} & r_{33} & t_z \end{bmatrix} \begin{bmatrix} X_w \\ Y_w \\ 0 \\ 1 \end{bmatrix}$$

#### Step 2: 单应性矩阵

将内参与外参结合：

$$s \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = \mathbf{K} \begin{bmatrix} \mathbf{r}_1 & \mathbf{r}_2 & \mathbf{t} \end{bmatrix} \begin{bmatrix} X_w \\ Y_w \\ 1 \end{bmatrix} = \mathbf{H} \begin{bmatrix} X_w \\ Y_w \\ 1 \end{bmatrix}$$

其中 $\mathbf{H}$ 就是**单应性矩阵** (3×3)，它将标定板上的 2D 点直接映射到图像 2D 点。

#### Step 3: 利用内参约束求解

单应性矩阵 $\mathbf{H} = [\mathbf{h}_1, \mathbf{h}_2, \mathbf{h}_3]$ 与外参的关系：

$$\mathbf{h}_1 = \lambda \mathbf{K} \mathbf{r}_1, \quad \mathbf{h}_2 = \lambda \mathbf{K} \mathbf{r}_2, \quad \mathbf{h}_3 = \lambda \mathbf{K} \mathbf{t}$$

由于旋转矩阵的列向量正交且单位长度：

$$\mathbf{r}_1^T \mathbf{r}_2 = 0 \quad \Rightarrow \quad \mathbf{h}_1^T \mathbf{K}^{-T} \mathbf{K}^{-1} \mathbf{h}_2 = 0$$
$$\|\mathbf{r}_1\| = \|\mathbf{r}_2\| \quad \Rightarrow \quad \mathbf{h}_1^T \mathbf{K}^{-T} \mathbf{K}^{-1} \mathbf{h}_1 = \mathbf{h}_2^T \mathbf{K}^{-T} \mathbf{K}^{-1} \mathbf{h}_2$$

令 $\mathbf{B} = \mathbf{K}^{-T} \mathbf{K}^{-1}$（对称矩阵，含5个未知数），从一幅图像可得两个线性方程。

#### Step 4: 求解内参

从至少 **2 幅不同姿态** 的标定图像，可以得到至少 4 个方程，解出 $\mathbf{B}$ 的5个未知数（实际上3幅即可超定求解）。恢复 $\mathbf{K}$ 用 Cholesky 分解。

#### Step 5: 求解外参和畸变参数

- 有了 $\mathbf{K}$，可从 $\mathbf{H}$ 恢复 $\mathbf{R}$ 和 $\mathbf{t}$
- 最后用 **Levenberg-Marquardt 非线性优化** 最小化重投影误差：

$$\text{Error} = \sum_i \sum_j \|\mathbf{x}_{ij} - \hat{\mathbf{x}}_{ij}(\mathbf{K}, \mathbf{D}, \mathbf{R}_i, \mathbf{t}_i)\|^2$$

其中 $\mathbf{x}_{ij}$ 是检测到的角点，$\hat{\mathbf{x}}_{ij}$ 是通过投影模型计算的理论角点，`D` 是畸变参数。

### 3.3 为什么需要多张图像？

标定板需要从**不同角度、不同距离**拍摄多张照片，因为：

1. 每张图像提供一组不同的外参 $(\mathbf{R}_i, \mathbf{t}_i)$
2. 外参变化越大，标定越准确（覆盖整个视场）
3. 至少需要 **3-5 张**，推荐 **15-20 张**

### 5.7 鲁棒检测增强版

`camera_calibration_robust.py` 相比基础版增加了：

```python
def preprocess_image(img):
    """CLAHE + 高斯模糊预处理"""
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    gray = clahe.apply(gray)
    gray = cv2.GaussianBlur(gray, (3, 3), 0)
    return gray

def find_chessboard_corners_robust(img, board_sizes):
    """多级fallback检测策略"""
    gray = preprocess_image(img)
    
    # 第一级：标准检测
    for bs in board_sizes:
        ret, corners = cv2.findChessboardCorners(gray, bs, None)
        if ret:
            return ret, corners, bs
    
    # 第二级： exhaustive 算法（更慢但更准）
    for bs in board_sizes:
        ret, corners = cv2.findChessboardCornersSB(gray, bs, cv2.CALIB_CB_EXHAUSTIVE)
        if ret:
            return ret, corners, bs
    
    # 第三级：缩小图像后检测（适合远距离小标定板）
    scale = 0.5
    gray_small = cv2.resize(gray, None, fx=scale, fy=scale)
    for bs in board_sizes:
        ret, corners = cv2.findChessboardCorners(gray_small, bs, None)
        if ret:
            corners = corners / scale  # 坐标还原
            return ret, corners, bs
    
    return False, None, None
```

**三级检测策略的意义**：
1. 标准算法速度快，适合大多数情况
2. Exhaustive 算法遍历所有可能的连通区域，适合光照不均
3. 缩图检测解决标定板在画面中太小的问题

## 7. 常见问题与调优指南

### 7.1 重投影误差过大 (> 1.0)

| 原因 | 解决方案 |
|------|----------|
| 标定板摆放姿态单一 | 让标定板覆盖图像的**各个区域**（四角、中心、倾斜） |
| 角点检测失败 | 检查 `findChessboardCorners` 返回值，过滤掉错误的检测 |
| 标定板不平/变形 | 使用玻璃面板打印的标定板，确保平整 |
| 方块尺寸输入错误 | 仔细测量实际方块尺寸（用卡尺） |
| 相机对焦不准 | 确保标定板在图像中**清晰锐利** |
| 曝光过度/不足 | 调整曝光使图像直方图分布均匀 |

### 7.2 相机检测问题

| 现象 | 解决 |
|------|------|
| `VideoCapture(0)` 打不开 | 尝试其他索引：1, 2, 3... |
| 图像上下颠倒 | `cap.set(cv2.CAP_PROP_SWITCH, 4)` 或使用 `cv2.flip(frame, 0)` |
| 延迟严重 | 使用 `cv2.CAP_DSHOW` 后端（Windows） |
| 多相机冲突 | 逐个释放 `cap.release()`，避免并发 |

### 7.3 去畸变后边缘有黑边

```python
# 方案1：使用 scale=0 裁剪到有效区域
newmtx, roi = cv2.getOptimalNewCameraMatrix(mtx, dist, (w, h), 0, (w, h))

cropped = undistorted[y:y+h, x:x+w]

# 方案2：接受黑边，但保留完整视野

undistorted = cv2.undistort(frame, mtx, dist, None, newmtx)
```

### D.3 标定项目中的典型应用场景

```python
import os
import numpy as np
from datetime import datetime

# 场景1：自动查找标定图像
def find_calibration_images(image_dir):
    extensions = ('.jpg', '.jpeg', '.png')
    return [
        os.path.join(image_dir, f) 
        for f in sorted(os.listdir(image_dir))
        if f.lower().endswith(extensions)
    ]

# 场景2：构建标定板世界坐标
def create_object_points(grid_w, grid_h, square_size):
    objp = np.zeros((grid_h * grid_w, 3), np.float32)
    objp[:, :2] = np.mgrid[0:grid_w, 0:grid_h].T.reshape(-1, 2)
    objp *= square_size
    return objp

# 场景3：保存标定结果并备份
def save_calibration_params(mtx, dist, rvecs, tvecs, output_dir):
    if not os.path.exists(output_dir):
        os.makedirs(output_dir)
    
    timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
    np.savez(
        os.path.join(output_dir, f'camera_params_{timestamp}.npz'),
        mtx=mtx, dist=dist, rvecs=rvecs, tvecs=tvecs
    )
    
    np.savez(os.path.join(output_dir, 'camera_params.npz'),
             mtx=mtx, dist=dist)

# 场景4：加载最近一次标定结果
def load_calibration_params(params_path):
    if os.path.exists(params_path):
        data = np.load(params_path)
        return data['mtx'], data['dist']
    return None, None
```
